Мини-апп, объявленный как `kind = "vue"`, панель монтирует внутри своего дерева, и всё, до
чего он дотягивается, приезжает одним объектом. Забрать его — `useNoro()`:

```ts
import { useNoro } from '@noroproject/module-ui'

const noro = useNoro()
```

Ничего отсюда не импортируется из панели: мини-апп собирается отдельно и её путей не знает.
`@noroproject/module-ui` при сборке превращается в то, что панель уже загрузила, поэтому
бандл не несёт Vue и весит килобайты.

## `noro.api` — ваши собственные ручки

```ts
const stats = await noro.api<Stats>('/me')
await noro.api('/reset', { method: 'POST', body: { hard: true } })
```

Путь относителен **вашему** модулю: `/me` становится `/api/modules/<ваш-id>/me`. Больше
отсюда не дотянуться ни до чего, и в этом смысл: мини-апп разговаривает со своей половиной
и ни с кем другим.

Метод по умолчанию `GET` или `POST`, если есть тело. Токен игрока подставляется за вас.
Отказ прилетает исключением, в сообщении которого — то, что сказал мастер.

| Поле | Тип | Замечания |
|---|---|---|
| `path` | `string` | ведущий слеш необязателен |
| `options.method` | `'GET' \| 'POST'` | по умолчанию — по наличию тела |
| `options.body` | `object` | уходит как JSON |

## `noro.ws` — сокет в реальном времени

Двусторонний обмен данными между мини-аппом и бэкендом модуля в реальном времени без ручной возни с WebSocket.

```ts
// Подписка на сообщения от вашего модуля:
const unsubscribe = noro.ws.on<OrderUpdate>((data) => {
    console.log('Пришёл фрейм:', data)
})

// Отписка при завершении работы:
unsubscribe()

// Отправка действия из вкладки браузера в модуль:
noro.ws.send({ action: 'bid', amount: 100 })
```

| Метод | Тип | Замечания |
|---|---|---|
| `ws.on<T>(callback)` | `(data: T) => void` | регистрирует подписчик; возвращает функцию отписки |
| `ws.send(payload)` | `(payload: any) => void` | отправляет фрейм в модуль; принимается как `WebMessage` |

## `noro.platform` — чтения панели

То, что панель и так знает и что не надо переписывать заново: кто смотрит, какие есть
сборки, что лежит на подсайте. Только чтение, всегда.

```ts
const me = await noro.platform.me.profile()
const towns = await noro.platform.hub.towns(slug, 1)
```

Записей здесь нет намеренно. Запись отсюда уехала бы с полномочиями того, кто открыл
страницу, а панель не может проверить, что выдали вашему модулю: эта проверка живёт на
Rust, вместе со списком возможностей. Поэтому писать — это ваша собственная ручка.

### Тот, кто смотрит

| Вызов | Отвечает |
|---|---|
| `me.profile()` | полный профиль смотрящего |
| `me.hubs()` | подсайты, где он состоит |
| `me.punishments()` | его взыскания |
| `me.sessions()` | его сессии в панели и лаунчере |
| `me.identities()` | привязанные Discord, Twitch и остальные |
| `me.tickets()` | его переписки с поддержкой |
| `me.cape()` | его плащ |

Права на это не нужны: это его собственные данные.

### Игроки и сборки

| Вызов | Отвечает |
|---|---|
| `players.byName(name)` | публичная карточка игрока или `null` |
| `servers.list()` | сборки в том виде, в каком их показывает сайт |
| `servers.rules(serverId)` | правила этой сборки |
| `rules.list()` · `rules.scopes()` | каталог правил |
| `legal.list()` · `legal.get(slug)` | правовые документы |
| `capes.list()` | доступные плащи |

### Подсайт

Каждый из этих вызовов первым принимает `slug` подсайта.

| Вызов | Отвечает |
|---|---|
| `hub.info(slug)` | сам подсайт: что включено, как называется |
| `hub.feed(slug, page?)` | лента, страницами |
| `hub.members(slug, { page, q })` | участники, с поиском |
| `hub.towns(slug, page?)` · `hub.town(slug, town)` | города |
| `hub.myTowns(slug)` | города, где состоит смотрящий |
| `hub.court(slug, page?)` | судебные дела |
| `hub.fines(slug, page?)` | штрафы |
| `hub.cards(slug)` | банковские карты смотрящего |
| `hub.communities(slug)` | сообщества, где он состоит |
| `hub.mapPlayers(slug)` · `hub.mapMarkers(slug)` | живая карта |

### `platform.call(method, args)`

Тот же диспетчер под низом, но по имени. Нужен, когда метод есть, а типизированный фасад за
ним не поспел; предпочитайте фасад — в имени можно опечататься, в функции нет.

## `noro.can`, `canAny`, `canOn` — что показывать

```ts
if (noro.can('noro.admin.users.view')) { /* рисуем кнопку */ }
if (noro.canOn('noro.hub.moderate', serverId)) { /* рисуем инструменты модератора */ }
```

Это отвечает, что **показать**, и никогда — что разрешить. Решение остаётся за мастером, а
ваша ручка проверит его ещё раз на входе. Спрятанная кнопка — вежливость; проверка в
браузере — не замок.

`canOn` принимает право первым, а сборку вторым: право — это вопрос, сборка лишь уточняет.

## `noro.t` — тексты

```ts
noro.t('mod-my-module-title', 'Мой модуль')
```

Ищет ключ в каталоге, который загрузила панель, включая локали модулей. Второй аргумент —
что показать, если ключа нет: без него на экране оказался бы сам ключ, а это хуже
английской строки в русской панели.

## `noro.format` — числа, деньги, время

| Вызов | Даёт |
|---|---|
| `format.money(minor, currency)` | сумму в валюте подсайта |
| `format.duration(seconds)` | `45s`, `1m 30s`, `2h 15m` |
| `format.date(value)` | абсолютные дату и время |
| `format.ago(value)` | «3 минуты назад», дальше недели — абсолютная дата |

`duration` принимает **секунды**, потому что этой единицей говорит мастер, и читает их
вплоть до секунды.

## `noro.paged` — списки, которые листаются сами

```ts
const top = noro.paged<Row>('/top', { perPage: 25 })
await top.load()
```

Оборачивает вашу же ручку, отвечающую `{ items, total }`. Вы получаете `items`, `total`,
`page`, `pages`, `search`, `pending`, `error` ссылками и `load()`, `next()`, `prev()` для
перемещения. Поведение то же, что у собственных списков панели, поэтому и пагинация
выглядит и работает так же.

## `noro.confirm` — спросить перед необратимым

```ts
const ok = await noro.confirm({
    title: noro.t('mod-my-module-wipe', 'Удалить всё?'),
    text: noro.t('mod-my-module-wipe-hint'),
    danger: true,
})
if (!ok) return
```

Собственный диалог панели, а не `window.confirm`: он похож на остальную страницу и не
выключается настройкой браузера. `danger: true` красит подтверждающую кнопку.

## `noro.notify`

`notify.ok(text)` и `notify.fail(error)` поднимают те же всплывающие сообщения, что и
панель. `fail` принимает объект ошибки как есть — он умеет прочитать ошибку мастера и
показать сообщение изнутри.

## `noro.user`

`{ id, username, mc_username }` смотрящего или `null`, если никто не вошёл. Проекция, а не
профиль: мини-аппу нет дела до прав, привязок и ссылок на текстуры, а узкая форма и есть то,
что не даёт полю панели случайно забрести в ваш код.

## `noro.navigate(path)`

Переводит панель на одну из её страниц. Только абсолютные пути: внешний адрес здесь был бы
переходом, о котором игрок не просил.

## `noro.vue`

Собственный Vue панели — та же копия, на которой она работает. Нужен, когда в точке входа
требуются `h`, `defineComponent` или `provide`; внутри компонентов импортируйте из `vue` как
обычно — сборка отобразит это сюда.

## Компоненты

`@noroproject/module-ui` реэкспортирует атомы, которыми нарисована панель, — поэтому
мини-апп похож на неё без единой строки стилей:

`AtomBadge` · `AtomButton` · `AtomCheckbox` · `AtomChip` · `AtomInput` · `AtomModal` ·
`AtomNumberInput` · `AtomSegmented` · `AtomSelectMenu` · `AtomToggle` · `EmptyState` ·
`NoroCard`

Это настоящие компоненты панели, а не копии: изменившийся вид кнопки доезжает до вашего
мини-аппа вместе с панелью, а не с вашим следующим релизом.

## Где мини-апп может появиться

Объявляется у каждого приложения в манифесте:

```toml
[[apps]]
placement = "cabinet"
kind = "vue"
entry = "app.js"
title = "mod-my-module-title"
icon = "i-lucide-box"
```

| `placement` | Где |
|---|---|
| `admin` | раздел в админке |
| `cabinet` | страница в кабинете игрока |
| `hub` | раздел подсайта сборки |
| `widget` | карточка внутри чужой страницы; нужен `slot` |

`kind = "page"` — альтернатива `vue`: статическая страница в песочнице, со своим
происхождением и разговором через мост. Она видит меньше и сломать может меньше. `vue`
выбирают обычно, потому что модули ставит сам владелец; для чужого кода песочница остаётся.

`permission` у приложения прячет пункт от того, у кого этого права нет. Как и везде здесь:
прячет, а не запрещает.
