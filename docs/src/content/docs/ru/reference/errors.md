## Одна форма в обе стороны

Мастер возвращает модулю `ModuleError`, и модуль возвращает мастеру `ModuleError`. Тип один
в обе стороны, поэтому второго набора держать в голове не приходится.

```rust
pub struct ModuleError {
    pub kind: ErrorKind,
    pub message: String,
    pub code: Option<i32>,   // код мастера, если ошибка пришла оттуда
}
```

| `ErrorKind` | Значит | Конструктор |
|---|---|---|
| `CapabilityDenied` | модулю не выдали то, что он просит | — |
| `NotFound` | объекта нет | `ModuleError::not_found(…)` |
| `Invalid` | аргументы не проходят | `ModuleError::invalid(…)` |
| `Conflict` | состояние не позволяет — не хватает денег, дубль | `ModuleError::conflict(…)` |
| `Quota` | упёрлись в предел: частота вызовов, размер файла | подождать и повторить |
| `Internal` | сбой внутри мастера | — |

Вернуть `Err` из обработчика — нормальный способ отказать. Паника ловится, становится сбоем
модуля и засчитывается ему — см. предохранитель ниже.

## Коды, которыми отвечает мастер

Ими отвечают ваши ручки, и они же видны в журнале вызовов в панели.

| Код | Имя | Когда |
|---|---|---|
| `1501` | `module_not_found` | модуля с таким id нет |
| `1502` | `module_disabled` | модуль есть, но выключен |
| `1503` | `module_cancelled` | обработчик отменил действие |
| `1504` | `module_timeout` | обработчик не ответил вовремя |
| `1505` | `module_failed` | обработчик упал или песочница поймала ловушку |
| `1506` | `module_capability_denied` | вызов в невыданное |
| `1507` | `module_quota` | упёрлись в предел |
| `1508` | `module_bad_package` | `.noromod` испорчен или его манифест не проходит |
| `1509` | `module_api_mismatch` | модуль собран против другого мажора ABI |
| `1510` | `module_migration_failed` | миграция вашей схемы не накатилась |
| `1511` | `module_route_not_found` | на такой метод и путь никто не отвечает |

## Предохранитель

Десять сбоев за пять минут — и модуль выключается сам, со строкой в общем журнале и
уведомлением во все открытые вкладки админки. Это сделано намеренно: модуль, сыплющийся в
цикле, хуже выключенного, а в три часа ночи логи никто не читает.

Что считается сбоем: паника, ловушка, таймаут. Намеренно возвращённый `Err` — нет.

## Таймауты

У обработчика пять секунд. У `#[init]` — тридцать: первичная настройка при включении
законно занимает больше, чем ответ на событие.

Вызов стерегут два таймаута, а не один. Собственное epoch-прерывание песочницы
останавливает модуль, крутящийся в своём коде, — но не может остановить того, кто застрял
**внутри** host-функции, и на этот случай есть второй, внешний срок.
