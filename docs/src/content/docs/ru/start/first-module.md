## Что понадобится

- Тулчейн Rust с целью wasm: `rustup target add wasm32-unknown-unknown`
- [Bun](https://bun.sh) — только если у модуля есть мини-апп
- По желанию [`wasm-opt`](https://github.com/WebAssembly/binaryen): режет `.wasm` примерно
  на треть, и без него сборка работает

## Поставить инструмент

```bash
cargo install cargo-noro
```

Он становится подкомандой cargo: `cargo noro …` из любого места внутри модуля.

## Создать

```bash
cargo noro new my-module
cd my-module
```

Получится работающий модуль: поле настроек, шаг при включении, обработчик события и
ручка — по одному каждого вида, и всё это можно удалить. `--ui none` оставляет модуль без
мини-аппа, `--bare` — без примеров, `--name "My Module"` задаёт отображаемое имя.

Идентификатор спрашивают один раз, потому что он разъезжается: в имя ящика, в манифест, в
префикс каждого ключа локали и в пакет мини-аппа. `cargo noro new` заполняет все четыре
разом.

## Собрать

```bash
cargo noro package
```

Результат — `dist/my-module.noromod`. Этот один файл и загружают.

Перед каждой сборкой отрабатывает `cargo noro check`. Манифест он читает теми же типами,
что и мастер, поэтому несуществующее действие возможности, ключ локали без префикса или
мини-апп, указывающий на несобранный файл, отвергаются здесь — до загрузки, а не после.

## Поставить

1. Админка → **Модули** → перетащите файл `.noromod`
2. Прочитайте, что он просит, и выдайте то, с чем согласны
3. Включите

Страницы, ручки и подписки модуля появляются сразу. Мастер при этом не перезапускается.

:::tip[Не пересобирайте пакет, пока пишете]
Покажите мастеру каталог модуля — админка → **Модули** → **Режим разработки**. Дальше он
читает wasm, мини-апп и локали прямо с диска и перезагружает модуль сам, как только вы
пересобрали; вторая половина этого — `cargo noro dev`. См.
[режим разработки](../../guides/dev-mode/).
:::

## На что влияет идентификатор

`id` в `manifest.toml` — не отображаемое имя. Он становится:

- схемой Postgres `mod_<id>`, где лежат ваши таблицы
- префиксом, который обязан нести каждый ваш ключ локали: `mod-<id>-…`
- путём ваших ручек: `/api/modules/<id>/…`
- корнем ваших узлов прав: `noro.module.<id>.…`

Отсюда и `[a-z0-9-]`, и то, что сменить его потом — это работа в четырёх местах. Выбирайте
один раз.
