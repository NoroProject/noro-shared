## Что это

Модуль — один файл `.noromod`, который владелец инстанса кладёт в админку. Он работает в
песочнице **внутри процесса мастера** и достаёт платформу через host-функции: вызов здесь
— это вызов функции, а не HTTP-запрос, и исходники мастера при этом остаются закрытыми.

## Как это выглядит

```rust
use noro_sdk::prelude::*;

pub struct Greeter;

#[noro::module]
impl Greeter {
    #[event]
    fn on_join(e: PlayerJoined) -> Result<()> {
        if e.first_join {
            log::info(format!("{} здесь впервые", e.player.label()));
        }
        store::user(e.player.id).incr("joins", 1)?;
        Ok(())
    }

    #[route(GET, "/me")]
    fn me(req: HttpRequest) -> Result<i64> {
        Ok(store::user(req.require_user()?).get("joins")?.unwrap_or(0))
    }
}
```

Это модуль целиком. Ничто из написанного выше не повторяется больше нигде.
